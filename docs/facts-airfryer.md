## ส่วนของภาพที่เป็นการอธิบายด้วยภาพ (ไม่ใช่ข้ออ้างตัวเลข)

- ลำดับทางเดินลม (พัดลม → ผ่านขดลวด → ลงข้างตะแกรง → ใต้ตะแกรง → ขึ้นผ่านอาหาร → กลับพัดลม) เป็นการวาดแบบง่ายของแนวคิด "ลมร้อนวนรอบอาหารจากทุกด้าน" (SF, IP, ING) ตำแหน่ง/ทิศจริงต่างกันตามรุ่น คลิปจึงพูดเพียง "วนรอบอาหาร"
- จอแสดง "200°C / 12:00" เป็นตัวอย่างค่าที่ตั้ง ไม่ได้อ้างว่าเป็นค่ามาตรฐาน (200 °C อยู่ในช่วงรุ่นทั่วไป ดูข้อ 6)
- ไม่มีโลโก้/ยี่ห้อในภาพ

| ปริมาตรห้อง 1-6 ลิตร เทียบเตาอบ 60 ลิตร, กำลังไฟ 1.5-2 กิโลวัตต์ | ING แหล่งเดียว และต่างกันตามรุ่น ไม่ใส่ตัวเลข |

| คำว่า "สุขภาพดีกว่า" / อะคริลาไมด์ | SABC อ้าง FDA เรื่องอะคริลาไมด์ แต่ยังไม่ได้เปิดอ่านหน้า FDA เอง จึงไม่ใส่ในคลิป ถ้าจะทำตอนต่อไปให้ตรวจ FDA/EFSA โดยตรง |
